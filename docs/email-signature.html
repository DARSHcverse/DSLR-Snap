How to use (Gmail, takes a minute)
  1. Open this file in Chrome or Safari.
  2. Drag over one signature below (from the logo to the last line) and copy it (Cmd+C).
  3. Gmail → Settings (gear) → See all settings → General → Signature → Create new → paste (Cmd+V).
  4. Under "Signature defaults", pick it for the address it belongs to (hello@ or support@), then Save changes at the bottom.
